# Getachew Ferede — SRE portfolio

Open **index.html** in a browser. It is self-contained: fonts, logos, styling,
interactions, and both PDF downloads are embedded, so no installation or network
connection is needed. LinkedIn, email, and phone links open the appropriate service.

Included:
- index.html — interactive, responsive portfolio
- downloads/Getachew_Ferede_SRE_Cover_Letter.pdf — general one-page SRE cover letter
- downloads/Getachew_Ferede_SRE_Portfolio.pdf — seven-page portfolio with projects, experience, and tool logos
- downloads/Getachew_Ferede_SRE_Resume.pdf — unchanged supplied PDF resume
- LICENSES — open-source font notices and logo source notes

Interactions: project filters, expandable work examples and career details,
tool categories, a three-part engineering focus panel, and mobile navigation.

Career dates follow the supplied PDF resume, including concurrent roles in 2021.
The two added project areas use responsibilities and tools already documented in
the resume. They do not claim new performance measurements or project-specific dates.
The AWS Cloud Practitioner item is historical, with the expiry listed on LinkedIn.

This package is ready to host as a static site. It has not been published.
